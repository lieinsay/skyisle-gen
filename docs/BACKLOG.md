## 优先级理由

1. **第一批必须最先**：R7 里所有人口/规模的结论、R6 里可用地与降水的关系、
   九格表的全部量词，都取决于「一个节点代表多大、多少人」。口径不冻结，后面全是返工。
   其中 **R10 零代码**（只改语义与文本），**R9 只加一个标量**，**R8 主要是配置**——
   这一批成本最低、收益最大。
2. **R2 可并行**：不碰生成逻辑，纯读现有 `wind.npz`/`climate_grid.npz`。
   而且 `CLAUDE.md` 写着「调试全靠看中间层」——先把可视化做好，第三批调参会省一半时间。
3. **第三批放后面**：R5/R6 都要重写核心场并重校三 seed（参照面积改动那次：
   γ 从 1 调到 0.5 才让 seed 2026 的 P7 过）。在尺度口径没定之前做，等于白做两遍。
4. **R7 最后**：它是新增的第 ⑩ 层，不动 ①–⑨，但输入是前面所有层的产物。

## R1 · 历法与行星尺度的双向自洽（提出于第 ① 层讲解后）

**原始诉求**
为了游戏性，一年 = 4 季，一季 = 28 天（合 112 天/年）。希望**通过设定节律反推行星大小**，
也可以**反过来配置行星大小来推出节律**，两个方向都要，且要求物理真实。

**涉及**
- ① `stages/s01_planet.py`、`config/default.toml` 的 `[s01.planet]`、`shared.day_range_km`
- ② 带界（`[s02.wind]` 四个 `*_top_deg`）与 `held_hou_scaling`
- ④ `stages/s04_climate.py` 的 `window`（可航季节比例）——目前算出来无人读
- 所有以「天」为单位的阈值：`shared.ships`（桥/小船/大船）、`s08.half_distance_days`

**已知难点与歧义**
1. **「天」在本项目是重载的**，必须先拆开：
   - 航行天：`day_range_km = 500 km` 定义的"一日航程"，是成本单位；
   - 太阳日：`rotation_period_hr = 24 h`，目前**完全没通电**（`held_hou_scaling` 默认 false）；
   - `s07.centers.yr_per_day`：把史前扩散的"距离天"换算成年，又是第三种含义。
   「一季 28 天」说的是哪种天，决定了这条需求接到哪一层。
2. **半径与年长没有直接物理耦合**。真实链条得走中间量，候选方案：
   - 年长 = 公转周期 / 自转周期 → 只约束这两个周期之比，不约束半径；
   - 若要牵动半径，需引入重力/密度（`g = GM/R²`，给定密度则 `g ∝ R`），
     再让 `g` 影响航速（`day_range_km`）或大气标高 → 间接影响带界；
   - 自转周期 → Hadley 圈宽度（`held_hou_scaling` 已有近似 `scale = clamp(√(rot/24), 0.5, 1.6)`）
     → 带界 → 骨架。这是目前唯一现成的"周期 → 世界"通路，但默认是关的。
3. **28 天很像朔望月**：4 季 × 28 天，每季恰好一个月相周期。若引入卫星，
   `一年 = 4 朔望月` 是一条自洽且有游戏性的硬约束，比"凑整"更真实。但目前世界里没有卫星。
4. **改带界 = 改骨架**。`docs/11-世界总图.md` 的带界（8/28/36/62°）是定稿。
   若让自转周期反推带界，等于让历法参数去改写定稿骨架，与 `check` 的 `SK-*` 校准直接冲突。

**未决问题（设计时要先答）**
- a. 「一季 28 天」的天 = 太阳日还是航行日？两者要不要锁定成同一个？
- b. 双向推导中，哪一组量是"自由变量"？（半径 / 自转 / 公转 / 航速 / 带界，五选二？）
- c. 允许历法反推去改带界吗？若不允许，历法就只能影响季节窗口，影响面很小。
- d. 要不要引入卫星与朔望月？

## R2 · 气象级的风场可视化（提出于第 ② 层讲解后）

**原始诉求**
做出风向可视化，包括风速、温度，**像真实的气象工具那样**。

**现状**
- 静态图 `viz wind`：只有一张 matplotlib 图（带号填色 + 少量箭头），`viz climate` 另有温度面板。
- 3D 操作台：风**只以贴图纹理的形式存在**——`web/bundle.py:build_texture()` 把风速做成
  条带细纹烘进 PNG，是装饰，不可查询、不可切换、没有数值。
- **操作台没有任何**风向、风速、温度图层；`temp` 场（`s04 climate_grid`）除了 `viz climate` 无人读。

**要做的**
- 风向：流线 / 箭头场 / 粒子动画（earth.nullschool 那种），随视角与缩放自适应密度。
- 风速：独立填色层 + 图例（现在 u 的实际范围 −25.7 ~ +14.8 m/s，两端都由 G 造成）。
- 温度：填色层 + 图例。
- 悬停/点击读数：该点的 u、v、风速、风向角、温度、风暴强度。
- 与已有的"边着色"配合：看一条航线时能同时看到它逆风还是顺风。

**难点**
- 数据已经在 `wind.npz`（1° 网格 181×360 的 u/v）与 `climate_grid.npz`（temp/storm/precip），
  但**目前没有走 `/api/world` 的数组通道**，只烘进了贴图。要新增一条网格场的传输路径
  （量化 + base64，参考现有 `_q8`），注意单文件导出的体积。
- globe.gl 上画流线/粒子需要自己写（不引第三方；项目要求完全离线、只用 vendor 里的 globe.gl）。

**→ 已于 2026-09-10 做完**（不碰任何生成逻辑，三 seed 基线不变）。实现要点见 `DESIGN-NOTES.md` 五：
- 传输通道：`bundle.build_grid()` / `GET /api/grid` / 单文件的 `INLINE.grid`，六个 1° 场量化 + base64（u/v 16 位、其余 8 位，共 ≈ 690 KB）；场列表在 `[web].grid_fields`。
- 风向：客户端积分 u/v 出流线，`pathsData` 虚线沿风向流动，密度随视高与屏幕可见范围自适应，条数上限 `[web].streamline_max`。
- 风速 / 海面温度 / 降水 / 风暴 / 风带：离屏 canvas 填色（可叠等值线）→ `globeImageUrl`，带刻度图例；默认地貌贴图仍是一个选项。
- 读数：悬停任意海面出 u、v、风速、风向（来向 + 吹向）、温度、降水、风暴、风带；探针面板加「气象」行。
- 顺逆风：边着色新增「顺逆风」——虚线流向顺风侧、颜色 = 逆向/顺向成本比 dir(−|c|)^α / dir(|c|)^α（复现 s06，与 `cost_ab/cost_ba` 对得上）；探针出边表与路径逐跳各加一列风因子。
- 未做：粒子动画（流线虚线已达到 nullschool 的效果）；水汽通量等 R6 的量待 R6 定案后再加进同一通道。

## R3 · 岛屿对风的反作用（提出于第 ② 层讲解后）

**原始诉求**
「岛屿对风的影响真的一点都没有吗」——要求重新思考。

**现状：确实一点都没有。** `s02_wind.py` 在 `s03_islands.py` **之前**运行，
风场是纯纬度函数 + G 涡旋，代码里不存在任何岛屿输入。

**关键发现：这不是新需求，是规格里已经写了、但没实现的一条。**
`docs/11-世界总图.md` 第 64–65 行原文：

> （岛的热容量太小，只影响局部。**密接群岛区会有自己的小尺度环流**——
> 这为「密接群岛内部往来廉价」提供了额外的物理理由。）

所以规格的立场是：**大尺度不受影响（"岛的尺度小到无法打散任何大尺度环流"是永暴带成立的前提，
不能动），但局地小尺度环流是存在的，而且被明确指定了用途——解释密接群岛内部往来为什么便宜。**
目前"密接区往来廉价"完全来自距离短（kNN 边短 → 成本低），没有任何风的贡献。

**物理上站得住的四种局地效应（按可信度排序）**
1. **表面粗糙度/摩擦**：密接区大量障碍物 → 近地面风速下降。最简单、最真实。
2. **热力日循环（海陆风式）**：岛升温降温快于周围空域 → 稳定的昼夜风。
   对多日航行会被平均掉，但它提供的是**可预期的时间窗口**（"早晚起风"），游戏性很好。
3. **地形抬升与背风风影**：叠层岛区（邻域高度标准差 > 320 m）造成迎风/背风不对称。
4. **风暴的轻微耗散**：密接区聚合摩擦更大。**必须是二阶小量**，否则与"永暴是物理必然"冲突。

**陷阱（设计时最容易搞反的一点）**
`s06_routes.py` 的无风惩罚是 `calm = min(calm_max, 1 + calm_kappa·max(0, 1 − v/v_ref))`——
**风速越低，成本越高**。所以若按效应 1 天真地在密接区调低风速，
结果是**密接群岛内部往来变贵**，与 docs/11 想要的结论正好相反。

正确的读法：规格说的"小尺度环流让密接区往来廉价"，指的是**有可靠可用的风**
（日循环稳定、方向可预期），而不是**平均风速更大**。
所以建模应当作用在**无风惩罚**上（密接区即使平均风速低也不吃无风惩罚），
而不是简单地缩放 `u`/`v`。

**管线顺序问题**
② 在 ③ 之前，岛屿无法反馈进风场。两条出路：
- (a) 新增 **②b 局地风修正**阶段，排在 ③ 之后：读岛密度/高度 → 产出粗糙度场、日循环强度场、
  风影场，供 ⑥ 成本与 ④ 风暴使用。缓存链方向仍然无环（② → ③ → ②b → ④/⑥）。
- (b) 不改风场，只在 ⑥ 的成本项里加一个"密接区局地环流"修正因子。改动小，但物理表述弱。
建议 (a)：② 保持为**行星尺度背景风**，②b 是**局地修正**，两者语义清晰，也便于 R2 分层可视化。

**未决问题**
- a. 局地效应只进成本，还是也进风暴强度（会牵动 ④ 与 P6 的 G 反事实）？
- b. 粗糙度用岛密度还是"岛密度 × 面积"（即刚做的集雨容量那类聚合量）？
- c. 日循环要不要真的进模型（需要 R1 的历法/昼夜先落地），还是先做成一个静态的"无风惩罚减免"？

  低空掠过时"透过云缝瞥见海面上大片惨白的礁"（docs/02 §九 指定的唯一痕迹，纯氛围）。
  本质是**给现有 height/layered 字段配一套叙事**，零机制成本。
- **机制层（违反原则甲，需先改铁律）**：让岛的高度/位置随时间演化、让玩家或文明能感知或影响它。
  原则甲的理由是「人类没有那么大的影响力能改变地质，就像地球一样」——
  这条是从三次失败尝试里沉淀下来的（见铁律二的反面教训）。

**未决问题**

- c. 若只是想让"世界看起来有地质史"，表现层能否满足？（成本几乎为零，且不动任何验收）

## R5 · 岛屿分布应有「板块」逻辑（提出于第 ③ 层讲解后）

**原始诉求**
「这个岛屿分布，其实就算这个浮空岛行星模型的**地壳运动**，所以也应该有类似大陆板块的逻辑」。

**这条重新定性了 R4。** R4 里我把地壳运动归为"违反原则甲"，那是把它当**过程/机制**看。
但本条指出：**岛屿分布本身就是这颗行星的地壳结果**。生成一个有板块结构的静态分布，
产出的是**静态格局**，没有任何机制或玩法依赖那个过程 —— **不违反原则甲**。
原则甲禁的是"让活人感知或影响地质"，不是"让地质留下结构"。
→ R4 的"表现层"与本条合并推进；R4 的"机制层"仍然要改铁律才能做。

**现状：分布是各向同性的分形噪声，完全没有结构。**
```
dens = 带基线(纬度) × exp(3.0 × 分形噪声)   # noise: base 8 格, 5 倍频, persistence 0.55
```
- 噪声各向同性 → 岛群是**斑块状**的，没有方向性。
- 现实群岛是**线状/弧状**的：岛弧（俯冲）、热点链（线性且有年龄梯度）、洋中脊、裂谷。
- 现在世界里唯一的线状结构是**人为画上去的**（绕道岛弧 = 绕 G 的一个圆环，`detour_arc_*`），
  它是骨架硬写的，不是长出来的。
- `layered`（叠层岛区）用的是**另一个独立噪声场**，与岛群分布无因果关系 ——
  现实里"堆叠"最该出现在碰撞/汇聚带。

**世界观里已经有现成的驱动力，不用新编。**
`docs/02-世界与地理.md §九` 原文：老岛下沉 → 土石沉底，**浮石骨架漂浮，随洋流汇聚嵌合**，
历经漫长岁月重新积累浮力，再极缓慢升起。
→ **"随洋流汇聚嵌合"就是板块逻辑的物理来源**：漂浮骨架在**辐合带**聚集嵌合成新岛群，
在**辐散带**被拉开成空域。而这颗行星的环流带（② 层）已经存在且是现成的辐合/辐散结构
（信风带表层向赤道的 `v` 分量就是辐合）。这条路径把 ②③ 和 §九 串成一条因果链，
比凭空加一层 Voronoi 板块更自洽。

**可能的实现路径（待设计，非定案）**
1. **辐合驱动**（最自洽）：由 ② 的 `v`（经向风）与带界剪切构造一个"漂浮物聚集势"场，
   密度沿辐合线增强、沿辐散线减弱 → 天然产生**纬向拉长的岛链**，而不是圆斑。
2. **板块/缝合带**（最像地球）：球面 Voronoi 分出若干"浮石板块"，给每条边界随机指派
   汇聚/离散/走滑三种类型；汇聚边界 → 密度峰 + **叠层**（碰撞堆叠，把 `layered` 的成因统一进来）；
   离散边界 → 密度谷（天然生成空域，甚至可以让 D 不再是手画的）；走滑 → 错断的岛链。
3. **热点链**：少数固定点 + 一个漂移方向 → 线性岛链且**年龄单调**，
   可与 ⑦ 的史前扩散（`arrival_yr`）呼应，也给 `height_m` 一个衰减梯度（老岛低、新岛高）。
4. 三者可叠加：板块定大格局，辐合定纹理，热点加少量长链。

**牵一发动全身，要预估的**
- 密度场是 ③ 的核心输入，改它会连锁到：候选边集 → ⑥ 干线/枢纽 → ⑦ 中心/地区 → ⑧ 文化场 → 全部验收。
  **三 seed 基线必然要重校**（参照上次面积改动：γ 从 1 调到 0.5 才让 seed 2026 的 P7 过）。
- 骨架修饰（赤道无岛核心、D 空域、G 盘与绕道弧）**必须仍然优先于**板块结构，
  否则 `SK-*` 骨架校准和 docs/11 定稿对不上。
- 若走路径 2 让 D 从离散边界"长出来"，等于把 `docs/11` 的定稿骨架改成涌现物 ——
  是加分项，但要先确认允许（原则庚："推不出即错"目前是靠窗内 argmax 保证的）。
- `noise_gamma`、`noise_base_cells` 等现有参数可能整体废弃或改义。

**未决问题**
- a. 走哪条路径？（辐合驱动 / 板块缝合带 / 热点链 / 组合）
- b. 允许骨架（尤其 D 空域）从板块结构里涌现，还是继续硬写？
- c. `layered` 的成因是否统一到汇聚边界？（会改变 `layered_height_std_m` 的含义）
- d. 要不要让岛的**年龄**成为一等字段（热点链/沉降梯度都需要它），
  以及它能否进社会推导（注意：年龄不是高度，不受原则乙约束，但要想清楚是否想要）。

## R6 · 水汽—降水—风采用成熟的现实模型 + 可视化（提出于第 ④ 层讲解后）

**原始诉求**
「这个世界都是岛屿，存在很大的岛屿，比如澳大利亚那么大的，应该是可能的，这就会影响风、雨了吧，
也只有这样才有可能形成沙漠吧」；关于降水量/水汽/风，**以现实世界的成熟模型为准**，并且需要可视化。

### 先澄清一个前提：沙漠不需要大陆，而且这个世界已经有沙漠了

地球上主要沙漠的成因排序：
1. **副热带高压下沉气流**（撒哈拉、阿拉伯、澳大利亚内陆、卡拉哈里）—— **纯纬度效应，与大陆尺寸无关**。
   澳大利亚是沙漠因为它坐在 20–30°S，不是因为它大。
2. **雨影**（巴塔哥尼亚、死谷）—— 需要地形，**不需要大陆**。
3. **大陆性/远离水汽源**（戈壁、中亚）—— **这条才真需要大陆**。
4. **冷洋流**（阿塔卡马、纳米布）—— 本世界无洋流，不可得。

现状：**机制 1 已经实现**。`s04` 的副热带降水谷（−0.38，中心 32°）让 32° 带降水降到 0.16，
全球 8.7% 的网格降水 < 0.2，**19.3% 的岛降水 < 0.3（九格表判 arid）**。沙漠是有的。
**机制 2（雨影）完全没做** —— 而这个世界有高度场（50 m 起，叠层区可到 ~2700 m），做得了。
参考：夏威夷大岛只有 10,400 km²、考艾岛 1,430 km²、怀阿莱阿莱山 1569 m，
却造出地球上最陡的迎风/背风降水反差之一。本世界最大岛 880 km²、高度可达 2700 m，
**尺度上完全够产生雨影**。所以"要沙漠必须有大岛"不成立，"要雨影必须有山"才成立，而山已经有了。

### 关于"澳大利亚那么大的岛"

数字：本世界最大岛 879 km²（直径约 33 km = 0.30°），**澳大利亚是它的 8755 倍**。
一个 1° 气候网格 ≈ 111 km 见方，最大岛只占其 **7.1%**。

允许大陆级岛屿会**同时推翻三条承重推导**，不是不能做，是要知道代价：
- `docs/02 §六`「岛上没有长期河流——**面积小，边缘就是虚空，水留不住**」→ 淡水只能靠集雨
  → 集雨设施规模效应强、不可分割、需分配裁决 → **一岛 = 一水共同体 = 最早的国家**。
  澳洲级岛屿有流域、有长河，这条推导对它整个失效。
- `docs/02 §七`「土地绝对有限，**没有垦荒、没有拓边、没有殖民**」→ 人口压力四条出路
  → **次子阶层（玩家角色的社会来源）**。大陆级岛屿有边疆。
- `docs/11`「岛的尺度小到无法打散任何大尺度环流」→ **永暴带是物理必然**。这是全世界的美术身份。

**折中方案（建议）**：不要大陆，要**尺度谱**。绝大多数岛维持 10–100 km²（集雨文明成立），
少数 1000–10000 km² 的"大岛"（有小型河湖、有明显雨影、有自己的局地环流），
仍比大陆小两三个数量级。这样三条推导全保住，雨影和局地气候差异也有了。
这与 R5（板块逻辑）天然配套：汇聚带产生少数大岛。

### 成熟模型的候选

- **Smith & Barstad (2004) 线性地形降水模型** —— 地貌演化领域的标准件（Fastscape 等在用）。
  稳态线性解，走 FFT，`numpy.fft` 足够（**不需要 scipy**，符合项目依赖约束）；
  181×360 网格毫秒级。输入：风场 u/v、地形高度、水汽标高、凝结时间、降落时间。
  输出：降水场，天然含迎风增强与背风雨影。
- **上风水汽追踪（advection–depletion）** —— 更简单：沿风场积分，水汽遇抬升凝结、
  沿程被耗尽，背风侧自然变干。物理表述弱一些，但更好解释、更好调。

### ⚠ 这个世界的垂直结构让标准模型不能直接套

`docs/02` 第 22 行：「**岛下是稳定的云带，云带之下是全球性的海洋。**海洋无人居住，但空艇可降至海面。」
所以：
- **水汽源在下方**（全球海洋经云带上涌），不是从上风水平输运来的 —— 与地球的海陆分布逻辑不同；
- **岛悬浮在空中，气流可以从岛的下方绕过** —— 地球上的山做不到这一点；
- 于是"迎风坡强迫抬升"只部分成立：来流会分成绕过 / 越顶 / **穿下** 三股。

这一条必须先做设计决策，直接照搬 Smith & Barstad 会得到物理上说不通的结果。
一个可能的处理：把浮空岛当作**部分透风的障碍**，引入一个"阻挡率"参数
（随岛面积与高度增大），只有被阻挡的那部分气流被强迫抬升。

### 可视化（与 R2 合并）

水汽通量、抬升速度、降水率、迎风/背风分量都要能单独看；R2 已经要求风向/风速/温度，
这里再加水汽与降水，共用同一套网格场传输通道。

### 未决问题
- a. 采纳"尺度谱"折中，还是真要大陆级岛屿（并接受重写 docs/02 §六§七 与 docs/11）？
- b. 用 Smith & Barstad 还是上风追踪？
- c. 浮空岛的"阻挡率"怎么定义？随面积、高度、还是叠层程度？
- d. 降水改成涌现量后，`[s04.climate]` 现有的四个高斯项（ITCZ/副热带谷/中纬峰/极地低）
     是保留作背景场，还是全部由模型算出来？（后者会牵动 ⑦ 适宜度与全部验收，需重校三 seed）

## R7 · 政治层缺失：世界尺度对得上春秋，但生成器只产出「邑」，没有「国」【可能触发整体重构】

**原始诉求**
「这个时期的人肯定没有航行整个星球的能力，就只是一个英国大小的星球的一小块，大概东亚区域的故事，
那岂不是全是村和村的故事，也太掉价了吧」。用户判断这条会**整体重构整个项目**。

### 先澄清：尺度本身是对的，不需要重构生成器

实测（seed 42）：

| 层级 | 规模 | 人口（@200 人/km²）| 春秋战国对位 |
|---|---|---|---|
| 一个岛 | 19 km²（中位）| 2,000–6,000 | **一邑**（采邑/宗族/水共同体）|
| 一个地区 | 中位 18 岛 / 816 km² | 16 万 | 宋、卫、许、曹一类小国 |
| 最大地区 | 671 岛 / 20,363 km² | **407 万** | 齐、楚、晋 |
| 全世界 | 8000 岛 / 255,821 km² | 2,560 万 – 7,670 万 | 战国末期的中国（2,000–3,000 万）|

150 个地区、绝大多数小、少数极大 —— **这正是春秋初年"诸侯数百"的分布形态**。
所以"全是村的故事"这个担忧在**数量上不成立**：不是村与村，是**邑与邑**，而邑正是春秋的基本单位。
「宗法分封」封的就是邑；「编户齐民」就是国君越过世卿、直接登记每一个邑的人 ——
岛屿的物理隔绝让这个张力变得可见可玩。

航行能力同样不是瓶颈：北带两大中心间干线 **39.2 天**（35 跳），绕行全球 80 天，
古代完全做得到。切开世界的是**赤道永暴带 A**（daily/trade/migrate 通过率 = 0，仅 envoy 0.03），
不是距离。

### 澄清补记：「新大陆」结构已经存在且已验证

用户后续澄清，「没有航行整个星球的能力」指的是**古代欧亚人从未到过美洲** ——
即世界上应存在一块本文明去不了、但确实有人的地方。**这个结构已经有了，而且比现实更彻底**（seed 42 实测）：

| | |
|---|---|
| 南半球 | 3,942 岛（49.3%），**有自己的文明中心**（−14.5°, 137.8°）与 **37 条本土起源特征** |
| 北→南 跨半球最大 reach | **0.022**（中位 0.0000）|
| 111 条特征中 reach > 0.1 传到对岸的 | **0 条** |

隔离来自赤道永暴带 A（daily/trade/migrate 通过率 = 0，仅 envoy 0.03）
加 ③ 层 6 条「几代人一次的国家远征」边 —— 相当于维京人到文兰：去过，没留下，没改变任何事。
`check` 的 `SK-south`（南半球隔离最深）已在守这条。**此项无需新增工作。**

以 north_east 中心为原点的「已知世界」四层同心圆（@200 人/km²）：

| 世界 | 门槛 | 岛数 | 陆地 | 人口 |
|---|---|---|---|---|
| 日常生活圈（口音） | daily reach≥0.1 | 465（5.8%）| 13,688 km² | 274 万 |
| 商旅世界（器物货币） | trade reach≥0.1 | 2,412（30%）| 75,463 km² | 1,509 万 |
| 文书世界（学问外交） | envoy reach≥0.3 | 4,041（50.5%）| 129,342 km² | 2,572 万 |
| 化外 | — | 3,942（49.3%）| 126,479 km² | 不知道有 |

envoy 恰好覆盖北半球全部 4,058 岛中的 4,041 个，然后在赤道处归零 —— 「四海之内」的边界是算出来的。

**「掉价」感的根源是单位**：用 km² 想，全世界陆地只有一个英国；用人口想，
已知世界 2,572 万人 = 战国末期中国。人口密度是地球古代农业社会的 10–15 倍
（集雨式园艺精耕，docs/02 §七 明写「提高单产 → 精耕细作、园艺化农业」）。
**戏剧性按人头算，不按公顷算。**

### 真问题：生成器只到「邑」，没有「国」这一层

- **地区（`s07` ⑦b）不是政治单位**。源码注释写明「地区划分，仅输出用，非文化边界」，
  操作台图例也写「着色仅为区分，不是文化边界」。它是按 daily 模式图距离做的**展示分区**，
  种子取自「中心 ∪ 枢纽 ∪ 最远点采样」，还会因为超过 250 岛被强制分裂。
  它**恰好**落在诸侯国的粒度上，但那是巧合，不是设计。
- **九格表把两层混着写**：① 报的是岛的面积（19 km²），⑤ 组织给的却是
  「邦国之制：宗法分封，公室与世卿之家分掌」——邦国是地区级的，面积是岛级的。
  读起来"掉价"的感觉多半来自这里，而不是来自世界本身。
- **没有任何东西生成政体**：没有国君、没有都城与采邑的隶属、没有疆界、没有兼并史、
  没有「哪些岛属于同一个国」。⑧ 的文化场是连续的（铁律五要求如此），
  但**政治单位必须是离散的**——这是文化层做不了、也不该做的事。

### 与铁律的一处潜在冲突（做政治层之前必须解决）

`docs/02 §八`：「守方优势巨大…**常态是长期割据均势。兼并极难**，非有压倒性的组织能力不可。」
但 `docs/01 铁律三` 要的是**春秋战国之交**——宗法分封被编户齐民取代，
而历史上驱动这场转变的正是**兼并战争**。若"兼并极难"是硬设定，转型的发动机就缺席了。
两条要么调和（例如：正因兼并极难，所以只有先完成编户齐民、榨出组织能力的那个国才能兼并
—— 这反而是更强的因果，秦制即如此），要么其中一条要改。

### 要做的（这才是"重构"的实际内容）

1. **新增第 ⑩ 层：政体生成**（不是重写 ①–⑨）。输入：地区/岛群、集雨容量、
   航线成本、枢纽、文化场。输出：离散的政治单位——国、都城、采邑隶属、疆界、
   附庸关系，以及一份可演化的兼并/分裂史。
2. **把"地区"正名**：要么升格为政体的骨架，要么与政体解耦、只做展示分区。
3. **九格表分层重写**：①③④ 写岛级（邑），⑤⑥⑧ 写国级（邦），
   ⑨ 文化位置仍是连续场（不动铁律五）。

## R8 · 增加陆地面积（提出于 R7 之后）【✅ 目标已定：25,000,000 km²】

> ### 修订版结论（在 R10「节点=岛群」确定之后重算，取代下文旧分析）
>
> **旧分析的两个错误**：
> 1. 把人口锚定在**汉代垦田**（533,000 km² / 6000 万人）—— 但汉朝只占公元 1 年
>    全球 2.5 亿人的四分之一，世界应该比一个汉朝大得多。
> 2. 「最大岛 1,771 km² 硬上限」是基于「节点 = 单岛」推的。

>    单个小岛多大属第三层，放大面积不再撞集雨文明的天花板。
>
> #### 诊断：现在根本不像群岛
>
> 给每个节点算「势力范围」= 最近邻距离² × 0.866（六边形填充），看陆地占了多少：
>
> | 地形类 | 势力范围（中位）| 当前陆地占比 |
> |---|---|---|
> | 密接群岛 | 1,675 km² | **1.02%** |
> | 中疏诸岛 | 10,423 km² | 0.18% |
> | 稀疏岛链 | 276,439 km² | 0.01% |
>
> 现实群岛：印尼 34.6% / 菲律宾 18.8% / 加勒比 8.7% / **巴哈马 2.0%**。
> **本世界最密的「密接群岛」只有 1.02%，是最稀疏的现实群岛的一半。**
>
> #### 目标：对齐古代全球人口
>
> 公元 1 年真实世界：汉 6000 万 + 罗马 5000 万 + 印度 4500 万 + 其余 9500 万 ≈ **2.5 亿**。
>
> ```
> 2.5 亿人 ÷ 100 人/km² → 可耕地 2,500,000 km²
>          ÷ 可用地率 0.10 → 陆地 25,000,000 km²   （现状 255,821 的 ×98）
> ```
>
> 全部节点势力范围合计 = **233,616,677 km²**（行星表面的 45.8%），
> 所以需要的**平均陆地占比 f = 10.7%** —— 落在加勒比与菲律宾之间，完全现实。
> 上限（f = 0.35，印尼水平）→ 陆地 81,765,837 km² / 8.18 亿人，头寸充足。
>
> #### 分层校验（全部对得上）
>
> | 层 | 数量 | 人口 |
> |---|---|---|
> | 一个节点（岛群 = 邑）| 8,000 | 3.1 万 ≈ 汉代半个县 |
> | 一个地区（诸侯国）| 150 | 中位 56 万，最大 2,100 万 |
> | **一个文明圈** | 3 | **≈ 6,300 万 ≈ 汉朝** ✓ |
> | **已知世界（北半球）** | — | **1.27 亿 ≈ 汉+罗马+印度** ✓ |
> | 全世界（含化外南半球）| — | 2.5 亿 = 公元 1 年全球 ✓ |
>
> #### 建模方式要换：绝对面积 → 陆地占比
>
> 现在是给每个节点抽一个**绝对面积**（对数正态 μ/σ）。放大到 ×98 时会**撞几何墙**：
> 12.2% 的节点陆地超过自己的势力范围（物理上不可能）。改成：
>
> ```
> 节点陆地 = 势力范围 × f
> 势力范围 = 最近邻距离² × 0.866
> f ~ 可配分布，均值 0.107，硬上限 0.35（印尼）
> ```
>
> 三个好处：
> 1. 旋钮直观，且能直接对着现实群岛校准（巴哈马/加勒比/菲律宾/印尼四个锚点）
> 2. **几何自洽由构造保证**，不会出现陆地超过势力范围
> 3. 「密接/中疏/稀疏/孤悬」四个分类第一次有了**定量含义**——f 就是「这一带有多少地」
>
> #### 新增未决问题（已于实现时裁决，见 DESIGN-NOTES 四点六：α = 1，f ∝ 密度；旧 β 与 μ/σ 废弃）
> - **f 如何随地形类变化？** 若 f 全局常数，稀疏区节点（势力范围 276,439 km²）
>   的陆地会是密接区（1,675 km²）的 165 倍，荒谬。
>   现实里 f 与密度**正相关**（密接群岛 = 陆地多，孤悬散岛 = 一块石头在汪洋里）。
>   需要定 f 与密度的关系式，并决定「节点陆地是否大致与地形类无关」（一个邑就是一个邑）。
> - 现有的 `area_density_beta`（面积~密度反相关，β=1.5）在新模型下**语义反转**，需重新推导。
> - `area_lognorm_mu/sigma` 是否整体废弃？
>

## R11 · 陆地增至 4.9% 后，风带不该再是木星式的层次分明（提出于 R8 定案后）

**原始诉求**
「因为陆地面积提高，我觉得现在应该是会影响风带了，不应该像木星一样层次分明，
而是有一定的变化，但我觉得没问题，这样更有趣」。

### 前提确实变了

`docs/11-世界总图.md` 与 `docs/02 §四` 的原始论证是：
「**本世界全球皆海洋，岛的尺度小到无法打散任何大尺度环流** → 大尺度气旋一旦形成便永不消散。」

这条在陆地占行星表面 **0.05%** 时毫无疑问。R8 定案后陆地占比升到 **4.9%**（地球是 29.2%），
量级变了两个数量级，「小到无法打散」不再是不证自明的，必须重新论证。

### 但永暴带必须活下来——而且现在有了更好的理由

永暴带是这个世界的美术身份与物理必然（`docs/02 §四`），不能因为加地就没了。
好消息是：**换个理由它反而更结实。**

地球的飓风登陆即死，是因为**同时**失去暖洋面的水汽源、并获得地表摩擦。
但本世界的岛**悬浮在海面之上**（`docs/02` 第 22 行：「岛下是稳定的云带，云带之下是全球性的海洋」）——
风暴经过群岛上空时，**下方的全球海洋仍在，水汽源从未被切断**，
只是多了一层 4.9% 覆盖率的悬空障碍带来的摩擦。

→ 新论证：**不是「岛太小」，而是「岛不接触海面」。** 这条与陆地占比无关，
在 4.9% 甚至更高时同样成立，比原论证更稳。**建议同步修订 `docs/02 §四` 与 `docs/11` 的措辞。**

### 会变的是什么：带结构从"纬线"变成"波状线"

4.9% 的悬空障碍能造成的是**扰动**，不是**打散**：

1. **摩擦亏损**：群岛密集区上空纬向风速下降 → 带内出现经度方向的强弱交替。
2. **尾流与背风涡**：密集群岛下风侧的风速亏损与湍流。
3. **绕流与阻塞**：极密集区让气流分叉，带界被推挤出起伏。
4. **定常波**：岛密度场的经向不均匀（③ 的分形噪声本来就是成簇的）激发波数 2–4 的驻波
   → **带界不再是纬线，而是有 ±几度起伏的波状线**。

注意**热力驱动的季风/定常波（地球上的主因）在这里弱得多**，因为岛下方仍是均匀的全球海洋，
下边界条件没有海陆之分。所以扰动幅度应当明显小于地球，**带结构仍然可辨**——
「有变化但仍是条带」正是用户要的效果。

### ⚠ 影响面极大：整个世界要从「一维」推广到「二维」

目前 ②④ 的几乎所有场都是 **|纬度| 的一维函数**（唯二的例外是 G 和两个噪声项）：

| 现在 | 变成波状带界后 |
|---|---|
| `s02` `u = f(\|φ\|)`、`v = f(\|φ\|)` | 真正的二维场 |
| `s02.band_id_of_lat(lat, bands)` | 要改成 `band_id_of(lat, lon)` |
| `s03` 带密度基线按 `band_id_of_lat` | 同上 |
| `s04` 降水/风暴/温度全是 `_gauss(\|φ\|, ...)` | 全部要接受局部带界 |
| **`s05` 的 Φ 穿越坐标 `(lat − lo)/(hi − lo)`** | **`lo/hi` 变成经度的函数** |
| `s07` 中心窗 `band == 1` | 同上 |

**最危险的是 `s05` 的 Φ 归一化**（`DESIGN-NOTES §二` 的核心设计）：
它依赖「带界是固定纬度」才能保证「任一单调穿越 Σf = 1 → 通过率恰为矩阵值」。
带界起伏后 Φ 必须改成沿**局部**带界归一化，`SK-perm` 校准要重做。

好的一面：这会给世界带来**真正的经度结构**，正是 R6（雨影）与 R5（板块）也想要的东西，
三条应当合并设计——都是「把一维世界推成二维」这同一件事。

### 建议实现路径
挂在 R3 提议的 **②b 局地风修正**阶段上（② 在 ③ 之前，岛屿无法反馈进 ②）：
- ② 保持**行星尺度背景带**（纯纬度函数，作为未扰动基态）
- **②b** 读岛密度/面积/高度 → 产出摩擦场、尾流场、带界位移场 `Δφ_band(lat, lon)`
- ④⑤⑥⑦ 改为读「局部带界」而不是全局常数
- 可视化（R2）分层显示：背景带 / 扰动 / 合成场

### 未决问题
- a. 带界起伏幅度取多少？（建议先定一个上限，例如 ±3°，保证「仍是条带」）
- b. 扰动是**诊断式**（由岛密度直接算出位移场）还是**动力式**（解一个简化的正压涡度方程）？
     诊断式便宜且可控；动力式更真实但要引入新的数值求解，且与「不引 scipy」的约束冲突。
- c. `s05` 的 Φ 沿局部带界归一化后，`SK-perm` 的校准口径怎么改？
- d. 永暴带 A（赤道）要不要也起伏？（若起伏，南北半球的隔离度会随经度变化 —— 可能出现
     「某个经度上南北稍微好过一点」的走廊，这会直接影响 `SK-south` 与 P4/P6）
