# 数据使用说明（DATA-GUIDE）

给读生成器产物的人与程序（Zhouzhu 的游戏与导出工具 `tools/export_skyisle.py` / `tools/export_planet.py`、操作台、营建器）：每个字段是什么、怎么用、不能怎么用。
**跟着字段写**（PLAN-NATURE 第九节）：哪一阶段加了、改了字段，说明在同一次改动里写进来；没写到的字段先看 DESIGN-NOTES 对应的节。

每个字段说六件事：**含义和单位**；**口径**（从哪量起、夸张没有）；**可信尺度**（多细以下是假的）；**推荐的还原方法**；**游戏能自由发挥的范围和上限**；**不能做的事**。

核心一条：**游戏补的细节，平均回生成器的格（岛群 100 m 一格）要等于生成器的数。** 补出来的岸线、山、河只能在生成器给的数周围抖，不能把数改了。

## 一、垂直结构：`planet.json` 的 `vertical`（① 写，PLAN-NATURE A1，2026-09-30）

设定：spec 13 第九节第 2–4 条。① 按 `[s01.atmosphere]` 纯换算写出，不改任何场；没有这一段的旧 run（A1 之前）`vertical` 是空的。

| 键 | 含义、单位 | 默认 |
|---|---|---|
| `datum_pressure_atm` | **零点**（浮层基准）的气压，atm。所有高度都相对零点、往上为正、m | 1.0 |
| `scale_height_km` | 大气标高 H，km。气压 p(z) = p₀ · exp(−z / (1000 H)) | 8.0 |
| `o2_fraction` | 氧的体积分数（与地球同） | 0.2095 |
| `sea_level_m` | 海面高度 | −6800 |
| `cloud_base_m` / `cloud_top_m` | 云带的底与顶（几乎全球的一层厚云；逆温层） | −6200 / −5000 |
| `keel_gap_m` | 云带顶到最低的岛底的间隙（风暴脚下永远是海洋，水汽从这里上涌） | 1000 |
| `keel_floor_m` | 派生：岛底不低于它 = 云带顶 + 间隙 | −4000 |
| `sea_pressure_atm` / `sea_o2_atm` | 派生：海面的气压与氧分压 | 2.34 / 0.49 |
| `pressure_formula` / `temperature` / `note` | 前端加的中文说明（公式、气温怎么随高度变） | |

- **口径**：零点不是地面、不是云带顶，是「气压约一个大气压的高度」。三 seed 的台面（③ 的 `height_m`）5–95% 在 +0.3 … +2.2 km、气压 0.96 … 0.76 atm，和地球上人住的陆地一样；全部在 +50 m … +3.5 km、0.99 … 0.65 atm（④ 摘要的 `surface_pressure_atm`）。
- **气温**：零点以上按 `[s04.climate] lapse_c_per_km`（6 °C/km）往上变冷；**零点以下取零点处的气温**（云盖反射阳光、云顶辐射冷却，云带是逆温层，下面又浓又稳）。
  ④ 的 `temp_sea` / `season_range_sea` 这些「海面口径」的量说的就是**零点处**（键名沿用，不是真的海面的气温）；`temp` 等「岛上口径」在台面 `height_m`。
- **可信尺度**：各层高度是设定的量级（spec 说「约」），生成器里只有零点、直减率与台面真的进了推导（④ 的温度），其余几个层只给游戏摆场景。
- **还原方法**：游戏要某高度的气压就按上面的公式算；要气温就「零点口径的气温 − 直减率 × max(0, z) / 1000」。
- **游戏能自由发挥**：云带的厚薄、起伏、云顶的形状，海面的浪——只要平均高度照这里。
- **不能做的事**：别把零点当地面或云带顶（旧设定「云带顶面 = 高度零点」作废，spec 13 第六节第 36 条）；别写死这些数（Zhouzhu 的 `VerticalDatum` 要改成从行星包读，PLAN-NATURE D4）。

### 生成器里别的「高度」

- ③ `islands.npz` 的 `height_m`：主岛「台面」= 主岛陆地高程的中位数（零点以上，m；DESIGN-NOTES 四点十九），④ 的岛上气温就在这个高度。不是峰高。
- ③ 的 `wall_m = max(0, height_m − keel_clearance_m)` 与 `[s03.islands] keel_clearance_m`（300 m）：②b 挡风用的迎风截面、④ 高原陆地性从哪算起、岛群地形的崖脚的一个**生成器内部的量**，
  **不是游戏里的岛底**（真的岛底在零点下三四公里，岛体是倒锥：岩层 + 浮石骨架，spec 13 第二节第 6 条）。改不改名、改不改数放到 A 验收之后另看（PLAN-NATURE 第十节第 7 条）。
- 岛群产物 `island.json` 的 `islands[]`：`surface_m`（台面）、`rim_m`（岸缘，崖顶）、`peak_m`、`keel_m`（崖脚）、`cliff_m = rim_m − keel_m`，都是相对零点的高度。
  岸缘与台面都在零点以上（岸缘 ≥ `[island.float] rim_floor_m`，seed 42 的 2,924 座岛最低 21 m）；崖脚可以在零点以下（往下浮的小岛，同一批里一成，最低 −199 m）。
  `terrain.npz` 的 `height` 与 `height.png`（16 位，× `height_png_scale_m_per_unit`）同一个口径，0 = 虚空。崖脚以下的岛体生成器不建模，游戏按 `keel_floor_m` 以上自己接倒锥。

## 二、降水：年雨、四季份额、降水线（④ 写，PLAN-NATURE A2–A3，2026-09-30）

设定：spec 13 第九节第 4–5 条（云带是逆温层、岛那一层默认干；副高下沉干、西风带与热带雨带湿；弱的岛群季风，季风的边就是 400 毫米线）。
四季各解一遍水汽（DESIGN-NOTES 四点四十四）；A2 之前的 run 没有下面带 † 的键。

| 产物 · 键 | 含义、单位 |
|---|---|
| `climate_grid.precip` / `climate_islands.precip` | 年雨的**相对值**：四季水量的平均，按全行星格点的 P98 归一，夹 [0.02, 1]。1 ≈ 赤道雨带的高值 |
| `climate_islands.precip_mm` † | 年雨，mm = `[s04.climate] precip_mm_ref`（4000）× 相对值，**线性**。行星层、岛群层、⑦、⑨ 都用这一条（旧的 150 + 3850 × p^1.3 作废） |
| `climate_grid.precip_share` [季, lat, lon] † / `climate_islands.precip_share` [季, N] † | 各季降水占全年的份额（和为 1）。季 1 的季中 = 北半球夏至（与岛群层的历法同）；南半球照同一季号，冬夏反过来 |
| `climate_grid.season_shift` [季] † | 各季带界整体南北挪了多少，°，向北为正（全球一个数，约 ±5°） |
| `climate_grid.lift` † | 抬过逆温层的比例，四季平均（0–1）：辐合、深对流、风暴、撞墙抬升，副高下沉压它 |
| `climate_islands.precip_eff_mm` † | 有效雨，mm：各季的雨 × (0.5 + 0.5 × 生长度)，生长度按**零点口径**的季温 5 → 12 °C（休眠季的雨只算一半） |
| `climate_islands.arable_frac_eff` † | **降水线**之后的可耕率 = ③ 的 `arable_frac` × 折线（有效雨 250 mm 0.15、400 mm 0.5、600 mm 起 1）。⑨ 的人口与岛群层的已垦额度读它 |

- **口径**：毫米是**群的年雨**（④ 的 1° 格点双线性插到群心），不是某个点的；岛群层按局地雨（海拔 × 迎风坡）把这个总量在群里重新分，群的均值不变。
  四季的毫米 = 年雨 × 4 × 份额（岛群层 A5 起这样分，`island.json` 的 `climate.seasons[].precip_mm`；风暴、航行窗口、风仍按每季的带界位移取样）。
- **径流**（岛群层，A5）：`terrain.npz` 的 `runoff_mm` = 局地雨 × 按格的 Budyko 径流系数（傅抱璞式 w = `[island.hydro] budyko_w` 2.6，
  潜在蒸散按 Thornthwaite：本格高度的季温、季中的昼长）；`island.json` 的 `hydro.runoff_mm` / `runoff_ratio` 是全群陆地的均值。河的流量、常年河、大堰能灌多少地都按它。
  冷的、湿的、高的地方径流系数大（spec 13 第九节第 6 条）：seed 42 的剖面群 500 mm 上下约 0.2–0.3、700 mm 约 0.35–0.4，各群最高的一成地比最低的三成大一倍。
- **可信尺度**：纬度带、岛密与岛稀、迎风与背风这一级（④ 的格点 1°，水汽在 2° 上解）是算出来的；群内的分布是岛群层的事。几十毫米的差别不可信。
  相对值按 P98 归一：换种子、改参数，毫米的零点是跟着全行星的雨带走的，不是绝对的物理量。
- **还原方法**：要某季的雨就「`precip_mm` × 季数 × `precip_share[季]`」；要逐日的就读岛群层的 `weather_y<年>.csv`（它按季的毫米配平）。
- **游戏能自由发挥**：一季里雨落在哪几天、雷雨还是连阴、云海漫顶的样子；群内哪片湿一点——只要季的总量照这里。
- **不能做的事**：别把相对值当毫米用（旧的换算与线性的差到三四成）；别拿 `arable_frac` 当已垦额度（那是「地」那一项，降水线之前的，④ 的 `catch` 与 ⑥ 仍读它）；
  别在行星层用岛上口径的温度推可耕率（高度会经可耕率漏进 ⑨，犯原则乙）。

#### 水汽预算诊断（2026-10-05，④ v10）

新增独立的 `s04_climate/moisture_budget.npz`，保留原生水汽求解格（默认 2°）及各季数据。它只增加诊断，不改变原有风、降雨、温度或岛群气候数组。`climate_grid.q` 仍是按水汽自身 P98 归一并裁切的显示值，不能当作相对湿度或 kg/m³。

| 字段 | 单位与口径 |
|---|---|
| `lats / lons` | 原生求解格心，度 |
| `water_column_mm` | 模型搬运层的等效水柱 mm（= kg/m²），形状 `[季, lat, lon]` |
| `rain_flux_mm_day / source_flux_mm_day` | 该层的降水汇与水汽源，mm/86400 s；尚未做降水显示噪声、上下限裁切 |
| `wind_u_ms / wind_v_ms` | 同季、同原生格的输送速度 m/s，不能换成年均风再算季节通量 |
| `rain_rate_per_day` | 原求解器降水衰减率，1/86400 s；逐格有 `rain_flux = water_column × rain_rate` |
| `model_to_column_mm` | 原始 q 到 mm 的共同换算系数 |
| `year_days_86400s` | 现有水汽方程使用的年长，日按 86400 s；默认 336 |

换算来自原有方程 `dq/dt = E − P − div(uq)`：若原始年均降水分位数为 `P_ref`，令 `a = precip_mm_ref / (P_ref × year_days × 86400)`，则 `q_mm=a×q`，`P_mm/day=a×P×86400`，`E` 同样换算。所有水量使用同一个系数；不再从独立归一后的显示 q 反推。数据存双精度以供收支核对。

**这是沿用现有降水标尺的模型量，不是独立实测的大气水汽。** 它不提供垂直湿度、云液水、林冠接触层或核心捕获效率；整柱水汽通量只能作为宽松筛查上界，不能直接计入河流。行星层不扣核心水，不意味着允许无限抽取；还要检验取水份额和潜热是否足够小。旧缓存缺少该文件时明确视为缺失；由四个旧气候文件读回的 `Climate` 调用 `climate_moisture_arrays` 返回空字典，需要本阶段重算或直接读取已有诊断文件，不补猜原量。

## 三、岛群地形：高程、岩性、岸距、崖层、地貌点（岛群层写，PLAN-NATURE B，2026-10-01）

设定：spec 13 第二节第 6、8、9 条（岛是两层：从海底带上来的岩层 + 浮石骨架；特殊的山按成因条件出）。DESIGN-NOTES 四点四十六。B 之前的岛群产物没有下面带 † 的键。

| 产物 · 键 | 含义、单位 |
|---|---|
| `terrain.npz` 的 `height`（与 `height.png`） | 高程，m，相对零点（第一节）。B1 起下切在原生分辨率（100 m）上做、每轮全岛填洼，谷是真切出来的（B 之前在 ≤ 320 格的粗网格上切再放大，谷宽几百米） |
| `terrain.npz` 的 `lith` † | 出露岩性（uint8）：0 虚空、1 石灰岩、2 泥灰岩（1、2 合称沉积盖层 = 海相石灰岩）、3 辉长岩、4 蛇纹岩、5 浮石（骨架）。`lith.png` 是它的图 |
| `island.json` 的 `islands[].strat` † | 这座岛的层序：`cap_m` 老岛顶上的硬石灰岩盖、`sediment_m` 沉积盖层总厚（含盖）、`gabbro_m` 辉长岩厚（再往下是蛇纹岩）、`bed_lime_m` / `bed_marl_m` 互层的单层厚、`crown_exhumed_m` 冠顶已剥去的深度——都已换算到最终高程（× 拟合的比例） |
| `island.json` 的 `lith` † | 各岩性占陆地的比例：`share` 全群、`share_main` 主岛；`classes` / `palette` 是类名与 lith.png 的颜色 |
| `terrain.npz` 的 `coast_dist_m` † | **带符号的亚格岸距**，m（float32）：陆地为正、虚空为负，岸线上为 0。岸线是岛形连续场 f = τ 的等值线（marching squares 求线段、再算到线段的精确距离），不是格子的边 |
| `terrain.npz` 的 `rockwall_m` † / `rockwall_dir` † | 崖层：坡 ≥ `[island.landform] rockwall_deg`（40°）的陆地格，`rockwall_m` = 本格 − 8 邻里最低的高差（m），`rockwall_dir` = 朝那一格的方位（16 向，0 = 北、顺时针每 22.5°；不是崖的格 255）。岸崖（陆地到虚空）另见 `cliff` |
| `island.json` 的 `landforms` † | 特殊的山，一处一条：`id`、`kind`（英文码）与 `name`（中文名）、`island`、`cell`（行、列）、`km`（群坐标）、各类的量（见下）；`landforms_note` 是各类的说明 |

`landforms` 的类（按成因条件出，不设配额；公里级的形状已经在高程里，100 m 以下的只记位置与尺寸、游戏建）：

| kind | 中文 | 条件 | 进了高程的 | 只记的量（键） |
|---|---|---|---|---|
| `fold_ridges` | 平行岭谷 | 多核岛的接缝带 | 层面与地面沿缝起伏，硬层成窄脊 | `area_km2`、`strike_deg`（走向）、`length_km`、`wave_km`、`n_ridges`、`fold_amp_m` |
| `tilted_block` | 掀斜断块山 | 多核岛里有一个核的强度 ≤ 0.32（明显老） | 整岛歪向老核、对侧岸缘翘起 | `dip_to_deg`（歪向）、`tilt_deg`、`scarp_m` / `scarp_max_m`（断崖高）、`span_km` |
| `tower_karst` | 峰林 | 老岛、沉积盖层、暖（≥ 16 °C）湿（≥ 1100 mm）的低处 | 峰间平地压低 | `area_km2`、`tower_h_m`（石柱高）、`density_per_km2`、`rain_mm`（石柱游戏建） |
| `glacier` | 冰川 | 峰高过雪线（最暖一季的气温与年雨定） | — | `area_km2`（雪线以上）、`ela_m`、`peak_m`、`n_cirques`、`ice_cap`（一半以上的地在雪线以上） |
| `cirque` / `horn` | 冰斗 / 角峰 | 雪线附近的谷头 / 三个方向以上都有冰斗的峰 | 冰斗刨成半碗 | 冰斗 `radius_km`、`floor_m`、`headwall_m`、`aspect_deg`、`ela_m`；角峰 `peak_m`、`n_cirques` |
| `collapse_scarp` | 临空断山 | 峰离岸缘近、岸缘高差大，按条件概率 | 岸边挖掉一个半圆（面积 ≤ 1%） | `radius_km`、`headwall_m`、`lost_km2`、`edge_relief_m`、`p` |
| `sky_mountain` | 天上的山 | 往上浮 ≥ 1 km、峰高过主岛的峰 | —（只是标签） | `float_m`、`peak_m`、`above_main_peak_m` |
| `gabbro_crags` | 辉长岩锯齿峰 | 辉长岩露在山地 / 高山的高处、成片、坡陡 | 硬岩大坍塌角自然出 | `area_km2`、`peak_m`、`slope_med_deg` |
| `serpentine_barren` | 蛇纹岩秃山 | 蛇纹岩出露成片 | 地表改稀草、陡处裸岩 | `area_km2`、`bare_frac`、`elev_lo_m` / `elev_hi_m` |
| `mesa` / `butte` | 方山 / 孤山 | 硬石灰岩盖的平顶、四周成崖（≥ 2 km² 叫方山） | 硬盖成崖自然出 | `area_km2`、`top_m`、`rise_m`（崖高）、`steep_frac` |
| `natural_arch` | 穿山天窗 | 岸缘被削薄的岬角碰上骨架空洞 | — | `spur_strike_deg`、`opening_m`、`spur_top_m`、`sees_clouds`、`void_id` |

- **口径**：层面在拟合（台面 = 行星层的 `height_m`、峰 − 岸缘 = 目标起伏）之前定、跟着同一个仿射变，所以哪一格露哪一层不因拟合而变；`strat` 里的厚度已经乘了拟合的比例。
  浮高把整座岛（高程、层面）一起平移；峰林、冰川在平移之后按本岛的气温判（浮上去冷了，雪线以上的地多了）。
- **可信尺度**：岩性按格（100 m），但层面是按岛的等效半径 × 0.25 抹开的平顺面——几百米以下的岩性斑块是侵蚀切过层面出来的，不是单独生成的；层厚是设定的量级（盖层约 400 m、辉长岩约 900 m），
  不对着哪块地球上的地层标定。岸距在岸线附近一两格内是亚格精度，离岸远了就是到最近岸线段的精确距离。
- **还原方法**：游戏要连续的岸线就取 `coast_dist_m = 0` 的等值线；要崖面就按 `rockwall_m` / `rockwall_dir` 摆崖（朝向是崖往下的方向）；岩性决定石头的颜色、质感与剥落物。
- **游戏能自由发挥**：100 m 以下的崖面、石柱、天窗的样子，岩层的纹理与互层的厚薄（只要按格的岩性对得上），岸线在一格以内的曲折（只要 0 等值线平均回来）。
- **不能做的事**：别拿 `lith` 推地质年代或矿（矿、石料、盐看资源层，它们已经读了同一套层面）；别把 `sky_mountain` 当成地形里有什么特别——它就是一座往上浮了很多的普通岛；
  别用格子的岸（`island_id ≥ 0` 的边）代替 `coast_dist_m` 做岸线（差半格到一格，D1 的 `gen_export.cpp` 改读它）。

## 四、岛群的水：河道、谷底、河的数据、集水核、地下水（岛群层写，PLAN-NATURE C，2026-10-01）

**2026-10-03 口径修订（ISLAND_VERSION=7，优先于本节历史说明）**：栅格 `w_ch_m/d_ch_m` 与河点 `w_bf_m/d_bf_m` 现在来自同一静态断面，`surf_m=bed_m+d_bf_m`。所有深度列均为中心最大深度；经验式 `0.35·Q^0.4` 是断面平均深度 A/W，经幂函数断面积积分换算，默认中心深度为其 1.65 倍。`*_mean` 指年均流量工况，不是水宽/水深的年平均。`q_bf` 兼容旧字段名，指既有 `bf_ratio_channel` 工程假设下的参考满槽流量，**不是某年最大日流量或已核实的平岸洪水**；流域 `bf_ratio/event_bf_ratio` 仍仅作该年水文统计。临时槽不再额外宽深减半，成形流量也不含未出露的凝结水。降雨、核心增益与常驻掩膜未调大。详见 DESIGN-NOTES 四点五十四。

设定：spec 13 第八节（集水核）、第一节第 7 条与第二节第 6 条（闭孔两层：岩层是含水层、浮石骨架是底）。DESIGN-NOTES 四点四十七、**四点四十九（水位面 B+A）**。
C 之前的岛群产物没有下面带 † 的键，而且**河道格的 `height` 口径不同**（C 之前是河床，C 起是平岸水面）：看 `island.json` 的 `hydro.channel_height`，
`"surface"` 是新口径，没有这个键的是旧的。**B 之前的产物（`ISLAND_VERSION < 2`）没有带 ‡ 的键**：看 `island.json` 的 `meta.island_version`。

- **口径**：流量都是年均的量级（Budyko 按格、局地雨）；平岸宽深按年均流量的下游水力几何（泰晤士河、莱茵河对过），没按平岸流量——干而暴的群（平岸 / 年均 8–13 倍）河道会比地球上同平岸流量的窄。
  逐日径流指数只由第 `year` 年的逐日天气推（一年，年际差别看别的年份的 weather），流域内各点共用一条。
- **可信尺度**：河道中心线按格（D8，100 m），曲流在格内看不出——`planform` 与谷底宽告诉游戏能摆多宽；比降在 500 m 上平均；河床质、悬沙是按公式的量级（差一个数量级以内），不是实测。
  集水核与泉线按格，泉线段约 1 km。
- **还原方法**：某点某天的流量 = `q_mean` × 所在流域 `index[day]`；水深按 d = `d_bf_m` × (Q / `q_bf`)^0.40、水面宽按 w = `w_bf_m` × (Q / `q_bf`)^0.26（**站内关系**，L&M 1964；平岸以下），超过 `q_bf` 就漫上谷底；不想查表也可以直接用年均口径：w = `w_mean_m` × (Q / `q_mean`)^0.5（下游关系）——两者在平岸处接上
  流速 = Q / (w·d)。河段型可按比降查 Montgomery & Buffington 1997（< 1.5% 滩槽、1–3% 平床、3–10% 阶梯深潭、> 10% 跌水）。
- **游戏能自由发挥**：河在 `fp_left_m` / `fp_right_m` 以内摆（曲流波长约河宽的 10–14 倍）；河床的石头按 `d50`；水色按 `ssc_mgl`；冰情按逐日气温；崖瀑、泉线渗水的样子；云雾林的雾。
- **不能做的事**：别把河的水面画得比 `height`（平岸水面）高，除非当天流量超过 `q_bf`；别让河道格的地表当水面（只有 `river_water` 是）；别把凝结水加回降水或天气（它不下雨，是凝在林子、岩面上的）；
  别在 `floodplain` 上放房子。


### 临时流水与常驻河（ISLAND_VERSION 6）

`pts` 第 21 列 `flow_regime`：0 临时流水路径，1 常驻河。大小 `level` 与供水类型分别读取；一条 segment 可以包含两种类型。临时路径不代表此时有水，也不代表泉眼。

每个出口有自己的汇水流域。常驻点读取该流域 `index`，临时点读取 `event_index`。当日流量 = `q_mean × 指数`；宽 = `w_mean_m × 指数^0.26`；深 = `d_mean_m × 指数^0.40`。指数为零，水面、流量和水深都为零，河槽仍保留。水力数据与指数保留六位小数，界面显示时再舍入。

临时流路由该流域分高程带的降雨、融雪输入驱动，按三倍快流时间常数的有限三角汇流窗退水；不会继承其余流域的基流。非零事件指数年均为 1，无事件输入为全零。临时流路的年水量不含凝结水，凝结补给留在地下并在进入常驻河后计入。

常驻河候选用不含集水核增量的降雨汇流阈值确定，增强集水核只增加已有河的水量。持续供水仍是岩性基流比例、退水时间和凝结水的流域近似；没有新增逐点泉眼判定，也没有模拟玩家改变地形后的临时径流改道。
`island.html` 点击中心线（含褐色断流路径）显示所选位置的当前宽、深、流量、估算平均流速、平岸宽深、汇水面积、供水类型和本年有水日；日期滑块与天气图点击同步刷新地图和数据。地图最小像素线宽只是示意，右侧数值是真实米数。断流时不画瀑布。
