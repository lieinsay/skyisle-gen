# 第三批设计稿：把世界从「只看纬度」推成「东西也有差别」

> 状态：设计稿已定（2026-09-10，第八节四项按默认）。实施进度：**第 1 步已做**（主岛 / 岛体 / 河流，只接文本与探针）。覆盖 BACKLOG 的 R3 / R5 / R6 / R11，外加新拍板的「河流」。
> 写给一段时间没看项目的人：先读一、二、八三节就够决定；术语在第九节。

## 一、这批要解决什么

现在的世界有一个根本简化：**风、雨、温度、风暴全由纬度决定**，同一纬度上东边和西边一模一样，像木星的条纹。
第 ② 步先算好风，第 ③ 步才撒岛，岛对风、对雨没有任何影响。

这批把顺序反过来：**先有岛的位置，再按岛算风和雨**。做完以后：

- 岛群分布有板块逻辑：岛弧、岛链、缝合带，不再是随机斑点（R5）。
- 岛群像一排悬空的山，让风减速、绕流、留下尾流，风带的边界变成有起伏的波状线（R3、R11）。
- 降水由水汽模型算出来：迎风面湿、背风面干（雨影），赤道湿、副热带干是算出来的而不是画上去的（R6）。
- 够大够高够湿的岛有河（新）。
- 今天做完的操作台气象层（R2）是这批的调试工具：改一版场，立刻能在球上看。

## 二、已拍板的决定（2026-09-10）

| # | 决定 | 备注 |
|---|---|---|
| 1 | **不要大陆级的岛**；但**允许河**，按地球常见程度：有山有雨的岛都有河 | 河不改变政治逻辑——浮岛并未妨碍交通，文明形态与地球相近 |
| 2 | 降水用**上风水汽追踪**，不用 Smith–Barstad 公式 | 后者假设气流全部翻山，这里岛的几何不同 |
| 3 | 岛体是**从云带顶立到山顶的浮山**：厚度随高度增长，底部离云带几百米 | 露出的陆地下面是更大的浮石托体；**没有「气流从岛底穿过」这一股** |
| 4 | 降水**全部重算**：岛的位置定了，风和雨按岛算 | 三 seed 必然重校，这是这批本来要付的代价 |

## 四、新的管线顺序

```
① 行星 → ② 背景风（纯纬度，不变，作为「未扰动基态」）
→ ③ 岛群（板块密度模型 + 主岛占比 + 岛体几何）
→ ②b 岛对风的扰动【新阶段】：摩擦、阻挡绕流、尾流、带界位移 → 扰动后的 u/v 与局部带界
→ ④ 气候：水汽追踪降水（雨影、辐合带）、温度、风暴、河流判定
→ ⑤ 障碍（Φ 归一化改读局部带界） → ⑥ 航线（读扰动后的风） → ⑦（中心窗读局部带界）→ ⑧ ⑨ 不变
```

缓存链仍然无环（② → ③ → ②b → ④ …）。②b 的实现位置两种选法，实施时定：
(a) 新模块 `s03b_localwind`，在 `pipeline.STAGES` 里排在 ③ 之后、④ 之前，产物目录 `s03b_localwind/`；
(b) 并入 ③ 的末尾作为第二份产物。倾向 (a)，语义清楚，R2 可视化能分层显示「背景 / 扰动 / 合成」。

## 五、各模块设计

### 5.1 岛群几何（③ 新字段）

- **主岛占比** `main_frac`：对数正态，均值 0.5，夹 [0.2, 0.9]；`main_area = area_km2 × main_frac`。
  现在只有群的陆地总和（中位数 2,500 km²，一成的群超过 5,900 km²），河与挡风都需要「最大的那一座」。
- **岛体**：云带顶面 = 高度零点；岛顶 = 现有 `height_m`（50–2,700 m）；岛底 = 固定间隙 `keel_clearance_m`（默认 300）。
  于是墙高 = `height_m − 300`（低于 300 m 的岛当作薄片，墙高取 0）。厚度随高度自动增长，符合决定 3。
- **迎风截面**：把一个群当成一道**多孔山脊**：宽度 ≈ √势力范围，实心率 = `land_frac`，高度 = 墙高。
  这三个量合成一个格点上的**障碍场** O(lat, lon) ∈ [0, 1]（墙高 ÷ 边界层厚度 × 实心率，再按群的范围抹到 1° 网格）。

### 5.2 板块逻辑（R5）

默认路径 = **板块缝合带 + 辐合纹理 + 少量热点链**（BACKLOG R5 的路径 4）：

1. 球面 Voronoi 分 20–40 块「浮石板块」，每条边界随机指派汇聚 / 离散 / 走滑。
   汇聚边界 → 密度脊 + 高度抬升 + **叠层**（`layered` 的成因统一到碰撞带，替换现在那个独立噪声场）；
   离散边界 → 密度谷（天然空域）；走滑 → 错断的岛链。
2. 叠一层由 ② 的经向风构造的「漂浮物聚集势」：辐合线密度增强、辐散线减弱 → 纬向拉长的岛链（`docs/02 §九` 的「随洋流汇聚嵌合」）。
3. 三到五条热点链：固定点 + 漂移方向 → 线性岛链，**年龄单调**；新增字段 `age`，老岛低、新岛高。
   `age` 不进社会推导（不是原则乙的禁区，但保持卫生）。
4. 骨架（赤道无岛核心、D 空域、G 盘与绕道弧）**继续硬写、优先于板块**，否则 `SK-*` 校准和 `docs/11` 定稿对不上。让 D 从离散边界「长出来」是以后的加分项。
5. 现有 `noise_gamma` 分形噪声保留为残余纹理，幅度调小。

验证：`SK-*` 全过；新增只报告的检查「岛链各向异性」（沿边界 / 跨边界的密度自相关比）。

### 5.3 岛对风的扰动 ②b（R3 + R11）

输入：② 背景风、③ 的障碍场 O。输出（都在 1° 网格）：摩擦亏损场、绕流分量、尾流场、带界位移 Δφ(lon)、扰动后的 u/v；另加每群一个「可靠局地风」标量。

- **摩擦**：`u' = u × (1 − k_f·O)`，密集群岛上空风速最多降三成。
- **绕流与阻挡**：气流分成绕过 / 翻越两股（没有穿下）。用障碍场的梯度给出水平偏转（`v' += k_b·∂O/∂x` 一类的势流近似），翻越比例 = 墙高 ÷ 边界层厚度。
- **尾流**：障碍下风方向指数衰减的风速亏损，长度 5–10°。
- **带界位移**：把每个带内的障碍纬向异常平滑后映射成 Δφ(lon)，目标幅度 **±2 至 5°**，带结构仍可辨——「有变化但仍是条带」。
  `band_id_of_lat(lat, bands)` 改成 `band_id_of(lat, lon)`，读带界 + Δφ。
- **可靠局地风**（R3 的陷阱）：⑥ 的无风惩罚是「风速越低成本越高」，若在密集区简单调低风速，密接群岛内部往来反而变贵，与 `docs/11` 想要的结论相反。
  正确做法是作用在**无风惩罚**上：密集区的热力日循环给出可预期的风，⑥ 用 `max(v, v_local)` 算惩罚，`v_local ∝ land_frac`。
- **风暴耗散**：`storm × (1 − k_s·O)`，k_s 很小，必须是二阶小量（永暴带不能被岛打散）。
- 新论证同步进文档：不是「岛太小」也不是「岛不接触海面」，而是「岛底与海面之间的间隙保住了水汽源」。

### 5.4 降水（R6）：上风水汽追踪

在 1° 网格上用扰动后的风解一个**二维稳态水汽收支**：

```
∂q/∂t + ∇·(q·u) = E − P          迭代到稳态（迎风差分，几千步，numpy 秒级）
E = E0 × g(温度)                   蒸发源：下方海洋经云带上涌，暖处多，经度方向均匀
P = q/τ × (1 + k_o × max(0, u·∇O))  凝结：基础时间尺度 τ；迎风面撞墙抬升加速降水
```

- **雨影自然出现**：迎风面 P 大、q 被耗尽，背风面干。
- **纬度结构自然出现**：信风向赤道辐合 → 赤道湿；副热带辐散 → 干；中纬又湿。现在手画的四个高斯项**全部退役**（决定 4）。
- 输出：`precip`（归一 0–1）、`q`（水汽）、`uplift`（抬升分量）、迎风/背风分量，全部走 R2 的网格通道可视化。
- 校准目标：干旱岛（降水 < 0.3）比例维持 15–25%（现在 19.3%），以免 ⑦ 适宜度与 P7 全部重来。
- 温度：保留纬度公式与直减率；密集群岛上空的微弱增暖先不做。

### 5.5 河流（新）

每群按主岛判定：`has_river = main_area ≥ 300 km² 且 height ≥ 400 m 且 precip ≥ 0.35`；
河的规模标量 = `main_area × precip`（集水面代理）。按这个门槛，预计**六到七成的群有河**——对应「地球常见程度」（多米尼克 750 km² 有 365 条河，夏威夷考艾岛 1,430 km² 有常年河）。
去处：⑨ 九格表 ① 地理、⑤⑧ 水与生计的文本；`catch`（集雨容量）公式**先不改**，河默认不进人口容量（决定 1：不影响政治），留一个参数 `river_capacity_bonus`，默认 0。

### 5.6 ⑤ 与 ⑦ 改读局部带界

- ⑤ 的 Φ 穿越归一化是 `(lat − lo)/(hi − lo)`，`lo/hi` 变成经度的函数 `lo(lon)/hi(lon)`；「任一单调穿越 Σf = 1」的性质仍成立，但 `SK-perm` 要重新校准。
- ⑦ 的中心窗 `band == 1` 改用 `band_id_of(lat, lon)`。

### 5.7 可视化（R2 通道扩展）

网格通道加 `q`、`uplift`、摩擦/尾流、Δφ；球上画带界线（背景 / 扰动后）与板块边界线；探针显示主岛面积、岛体墙高、是否有河。

## 九、术语表

- **节点 / 岛群 / 邑**：生成器里的一个点 = 一个岛群 = 几十座小岛 = 一个基本政治单位。
- **主岛**：一群里最大的那座岛，本设计新加的量。
- **岛体 / 托体 / 间隙**：露出的陆地下面托着它的浮石；岛底离云带顶的距离叫间隙。
- **带界**：风带之间的分界纬度（信风、无风带、西风、极地）。**局部带界**指它随经度起伏后的值。
- **Φ 归一化**：⑤ 计算跨越一条风带障碍时的通过率的办法，把纬度换算成「穿过了这条带的几分之几」。
- **三 seed / 重校**：42、7、2026 三个随机种子的验收必须全过；改核心公式后要重新调参让它们过。
- **雨影**：山的背风面因为水汽在迎风面已经下光而干燥。
- **上风水汽追踪**：顺着风把水汽一路带过去，遇抬升就下雨、下过就变干的降水算法。
- **板块缝合带**：两块浮石板块相撞的地方，岛群密、叠层多。**辐合 / 辐散**：气流汇聚 / 散开的地方。
- **②b**：新加的「岛对风的扰动」阶段，排在撒岛之后、气候之前。
- **STAGE_VERSIONS**：每一步代码的版本号，改了代码不加号旧缓存会被当成命中。
