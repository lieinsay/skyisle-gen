# 岛群生成器设计稿：从行星上的一个点，生成一个能落脚的岛群

> 状态：**已实施（2026-09-17，六步全部完成）**：`zhouzhu_gen/island/`，命令 `zhouzhu island <节点> | check <节点> | batch --sample 30`，操作台探针里「生成此岛群」。
> 实现记录与三 seed 批跑统计见 `DESIGN-NOTES.md` 四点十四；参数在 `config/default.toml` 的 `[island]` 段；`CLAUDE.md` 有架构与默认值速查。
> 与本稿的差异：季中 = 二分二至（季 1 季中 = 北半球夏至），温度 / 带界摆动的相位滞后由 skeleton 的 τ 推出（海面 ≈ 55 日），所以海洋性地方的最热季常落在夏至后一季；
> 集水盆地按「河口集水区」而非岸段切；湖只保留每岛最大的 1–2 个深 ≥ 5 m 的洼地，其余洼地抬平；IS-daily 用 60 年样本并加了标准误判据（30 年时单季标准误 ≈ 5%）。
> 拍板五项与第八节 a、c、e 按默认。骨架第二版已实施（`PLAN-SKELETON2.md`）：5.4 的季节强度已在管线 s04 实现（`skeleton.season_range`），本生成器直接复用；
> 一年 336 日（4 季 × 3 月 × 28 日）、倾角 34°，5.4 / 5.5 里「112 天」「一季 28 日」按新历法读（逐日天气是 336 天，一季 84 日）。下文 5.4 的 seed 42 粗估是旧骨架的数，已过时。
> 写给一段时间没看项目的人：先读一、二、八三节就够决定；实现细节在第五节。

## 一、要解决什么

行星生成器做到「岛群」这一级为止：一个节点 = 一个岛群 = 一个邑（D65）。它知道这个群有多少陆地、主岛多大、多高、有没有河、年降水多少、风从哪来，
但**群里有哪些岛、岛上是什么样子、一年里哪天下雨**，它一概不知——这是 `docs/11` 开头声明的**第三层**，一直空着。

游戏需要的恰恰是这一层：主家选址要看地形和水，农事要看季节和雨，航行要看哪天起风暴，场景美术要有高程和地表可依。

岛群生成器做的事：**给一个节点号，按行星生成器的产物做约束，生成这个群的内部结构、岛内地形与一年的天气。**
结果必须和行星层对得上（陆地总量、主岛、峰高、可耕率、有无河、年均气候），但**不回灌管线**。

## 五、各模块设计

### 5.1 群内布局

- **岛数**：`n = clip(round(n0 × (area/中位 area)^0.35 × lognormal(0.25)), 12, 80)`，n0 = 30（「一群数十座」）。
- **大小**：主岛 = `main_area_km2`；其余 n−1 座按 Zipf（指数 ≈ 1.1）分配 `area − main_area`，最小一座不低于 0.3 km²（「只够一户人家的孤石」）。**总和严格等于 `area_km2`**。
- **位置**：主岛放中心；其余按泊松盘 + 主岛引力依次放置，**相邻岸线间距 1–15 km**（「五到十五公里，半小时可达」量的是岛心）。
  汇聚带上的群（`boundary_kernel` 高、`btype`=汇聚）沿板块边界走向拉长成岛弧；离散带上的群更散。
- **高度**：主岛峰高 = `height_m`；其余峰高 = `height_m × U(0.35, 0.95)`；**叠层群**（`layered`）改为围绕群均值 ±400 m 分层，出现「上下错开」的岛。
  岛底统一在云带顶上约 300 m（`keel_clearance_m`，与 ③ 同口径），峰高低于 300 m 的岛当作薄片。
- **连接**：岸线间距 ≤ `bridge_max_km`（默认 2 km）且高差 ≤ `bridge_max_dh_m`（默认 250 m）→ **索桥**；否则**短渡**。
  另算一张**导水槽网络**：以主岛为根的最小生成树，只走索桥边（`docs/02 §六`：跨岛集雨网络）。

### 5.2 岛内地形（高程）

每座岛在同一张群栅格上生成（默认 100 m/格，群外框上限 2048 × 2048，超出则自动降到 200 m）。

1. **岛形**：以面积定半径的椭圆（长轴沿板块边界走向）→ 域扭曲噪声打破轮廓 → 二值化后按面积二分反解阈值，**岛面积误差 < 1%**。
2. **基形随岛龄**（`age` 0 新 → 1 老）：
   - 新岛（< 0.3）：单个或并列火山锥，坡陡，放射状沟谷；
   - 中年（0.3–0.65）：切割后的山脊与谷地，峰偏离中心；
   - 老岛（≥ 0.65）：低缓台地与宽谷，边缘残丘。
   基形 + 分形噪声（新岛加脊状噪声）→ 缩放到「岸缘高度 → 峰高」。
3. **侵蚀**：简化的水流侵蚀（流量 × 坡度的冲刷 + 热力坍塌若干轮，纯 numpy），让沟谷连通、给河留出谷地。主岛多几轮，小岛少几轮。
4. **崖缘**：浮岛边缘就是虚空。岸线向内一两格标为崖缘，高程保持，**不向海面收敛**；崖高另记（岸缘高程 − 岛底）。

### 5.3 水系、地表与可耕地

- **流向与汇流**：D8 流向 + 洼地填平；汇流量 × 本岛年降水 = 径流。
- **河**：行星层 `has_river` 为真 → 主岛上**必须**出现至少一条通到崖缘的常年河（调汇流阈值直到成立），河的规模对齐 `river_size`；
  为假 → 只有季节性溪涧，没有常年河。小岛一律只有溪涧。
- **湖**：填平后面积 ≥ `lake_min_km2` 的洼地保留为湖，默认少见（大岛偶有）；有湖的岛在 `island.json` 里标出（R9 推论 1 的素材，只呈现不推导）。
- **集水盆地**：主岛按分水岭切出盆地；≥ 2 个大盆地时标出（R9 推论 2 的素材）。
- **地表分类**（每格一类）：崖缘 / 裸岩 / 高山草甸 / 林地 / 灌丛 / 草坡 / 可耕地 / 梯田（可耕且坡度较陡）/ 湿地 / 河道 / 湖。
  由海拔温度（海面温度 − 6 °C/km × 高程）、坡度、汇流、岛龄（土层厚度）、迎风 / 背风打分决定。
- **可耕地**：适宜度 = f(坡度, 土层, 温度, 离河远近, 非崖缘)，**按分位取最高的那部分，使全群可耕地 / 陆地 = `arable_frac`（误差 < 0.005）**。
  这保证与 ③⑨ 用的可耕地口径一致。

### 5.4 季节气候

行星层只有年均值。季节由「风带随太阳南北摆动」得到，强度用热惯性从轨道参数推出。

**季节强度**（决定 5：按实际位置推，不手调）。驱动 = 日照的年变化（纬度 × 倾角 20°）；响应 = 一阶热惯性，时间常数 τ 由「海洋性 / 陆地性」决定：

```
ω = 2π / 112 日
振幅保留 A = 1 / √(1 + (ωτ)²)      相位滞后 = atan(ωτ) / ω
海洋主导 τ ≈ 110 日 → A ≈ 0.15（同 τ 在地球上 A ≈ 0.45）：一年太短，海洋几乎来不及升温降温
陆地主导 τ ≈ 8 日   → A ≈ 0.91（地球 ≈ 0.99）：陆地的季节几乎不受短年份削弱
温度半振幅 = 日照年变化的一阶谐波 / λ × A，λ ≈ 10 W/m²·K（按地球中纬大陆与洋面定标）
```

陆地性由三项合成：周边岛群的陆地覆盖（`wind_local.land`）、主岛大小（大岛内陆更「大陆」）、岛的高度（岛在云带之上，峰越高越脱离下方洋面的调节，类比青藏高原）。

**全量统计（2026-09-18，`zhouzhu island stats`，骨架第二版三 seed）**：岛上全年温差中位 22 °C，**57–60% 的群 ≥ 20 °C（四季分明）**，西风带以北全部如此；
信风带 8–28° 的群一半是冷暖两季（温差 8–20 °C）、一半是风暴季，雨旱季只占 4–5%（副热带干侧）；赤道永暴带六到八成风暴季、其余常夏。全球常夏只剩 1%。
开工前按旧骨架（核心在 14–18°N）粗估的「8% ≥ 16 °C、八成六在信风带」已作废：核心北移到温带后，文明核心就是四季分明的。

每季（取季中那一天）：

- **带界偏移** `Δφ = k_shift × 倾角 × A × cos(相位)`，k_shift 默认 0.35（地球上赤道辐合带随 23.4° 倾角摆约 ±8°）。夏半年向极移，冬半年向赤道移。
- **降水 / 风暴 / 风**：在行星层的 1° 网格上，取「本岛纬度 − Δφ」处的值（按局部带界做带内相对坐标，不按纯纬线），
  得到四季的原始值，再**整体缩放使四季平均 = 本岛年均值**。结果：副热带边缘的岛会出现明显的雨季 / 旱季，带中心的岛四季相近。
- **温度**：年均海面温度 + `T_amp(纬度) × A × cos(相位)`，`T_amp` 按地球纬度分布 × 倾角 / 23.4°；岛上各格再减海拔直减率。
- **航行窗口**：四季的 `window` 同样摆动后缩放到年均，给出「哪一季能出远海」。
- **南北半球反相**；季与月相对齐（`docs/02 §二`：一季恰是一个月相周期），一季 28 日。
- **季的性格与命名**（决定 5）：比较四季的温度、降水、风暴、航行窗口各自的年内差异，按主导那一项给整个地方定季型，再给每季定性：

  | 季型 | 判据（默认阈值） | 四季的叫法（示意，名字是软的） |
  |---|---|---|
  | 四季分明 | 温度半振幅 ≥ 10 °C（全年温差 ≥ 20 °C，上海、郑州一级） | 暖 → 热 → 凉 → 冷（按实际排序） |
  | 冷暖两季 | 4–10 °C 且温度是最大差异 | 暖季 ×2 / 冷季 ×2 |
  | 雨旱季 | 最湿季 ≥ 最干季 × 2.5 | 雨季 / 转季 / 旱季 / 转季 |
  | 风暴季 | 风暴或航行窗口的季差最大 | 风暴季 / 平静季 / 过渡季 |
  | 常夏（常寒） | 以上都不达标 | 不分季，只按月相计 |

  `climate.json` 同时给出每季的数值与标签；阈值在第八节里可改。
  这正好给第三幕「历法统一」备了素材：不同的邑按不同的道理分季，统一历法抹平的不只是日期。

### 5.5 逐日天气（112 天，按年份可复现）

- **晴雨**：每季一个两状态马尔可夫链（干→湿、湿→湿的概率），由该季雨量与雨日比例反解；雨量取伽马分布，缩放到该季总量。
  单年总量围绕气候值自然波动；**多年平均严格回到气候值**（校验取 30 年样本）。
- **风暴**：按该季风暴强度生成持续 1–4 天的事件；风暴日强制大风、大雨、禁航。
- **风**：围绕该季平均风向风速的 AR(1) 扰动；风暴日另算。
- **温度**：季节曲线（逐日平滑插值，不是四个台阶）+ AR(1) 日际扰动。
- **云海漫顶（雾）**：这个世界的云在岛下面。低岛（峰高 < 800 m）在静风、潮湿、清晨更易被云海漫上岸缘——作为天气类型输出，是本世界独有的天气。
- **每天输出**：日序（季 / 日）、天气类型（晴 / 多云 / 小雨 / 大雨 / 云海漫顶 / 风暴）、降水 mm、日均温、风向风速、能否出航。

## 九、风险

- **侵蚀耗时**：纯 numpy 的水流侵蚀在 2048² 上可能偏慢。先限轮数；不够再只对主岛做全分辨率、小岛降采样。不引入 scipy（CLAUDE.md 约定）。
- **河的约束可能和地形打架**：极老、极平的主岛可能很难自然成河。策略是先调汇流阈值，再不行就沿最长谷线刻一条。
- **季节摆动取样跨过永暴带**：赤道附近的岛在偏移后可能取到永暴带内部的值。偏移按局部带界做带内相对坐标，并对 A 带（赤道永暴带）边界夹断。
- **「季节约为地球一半」与既有文案**：已查 `docs/`，没有「寒冬」「酷暑」「四季分明」一类写法；`docs/11` 第 40 行「季风效应极弱，风系接近纯行星风系」与此一致。
