> 2026-09-28 调研，供 `PLAN-TOWN.md` 第六节的风格卡与 `config/town/styles/*.toml` 取数。
> 标注：**无标记** = 数字出自核对过的来源页面；**†** = 只在检索摘要里见到、未逐页核对；**估** = 估计或由来源数字推算。
> 换算：明清 1 里 ≈ 576 m；1 亩 ≈ 667 m²；1 perch / rod = 16.5 ft ≈ 5.03 m；1 間 ≈ 1.82 m（京間 ≈ 1.97 m）。

## 附：村落平面形态的量化指数

- **浦欣成（2012，浙大博士论文）**：把聚落总平面拆成边界、空间、建筑三个要素，对应形状、结构、秩序；分别用 100 m、30 m、7 m 三种虚边界闭合出三层轮廓，取加权平均形状指数，再结合长宽比 λ 给边界分型；边界的局部特征另用密实度、离散度、边缘空间平均宽度三项指数 [89]。
- **常用阈值与公式** [90]：长宽比 λ = 长 / 宽：λ < 1.5 团状；1.5–2 带状倾向的团状；> 2 带状。形状指数 S = P·√λ / [(1.5λ − √λ + 1.5)·√(Aπ)]：圆形 S = 1，越大越不规则。
- **杨希（2020）综述**：平均最近距离、斑块密度、斑块面积均值与标准差、平均最近邻距离、边界形状指数、分形维数、空间句法 [91]。
- **Clark–Evans 最近邻指数**：R = 实测平均最近邻距离 ÷ (0.5 / √ρ)。R < 1 聚集，≈ 1 随机，> 1 趋于均匀（六边形上限约 2.15）[92]。例：金沙江流域传统村落 R = 0.165，高度聚集 [93]。这类研究多在区域尺度（村与村之间）做，用来校验「户与户」的布局时要在建筑尺度上重新计算。
