# 12 · 扩散模型（形式规格）

本文档是文化梯度的**形式化规格**，同时是「行星地形与文明生成器」的**规格书**。

## 〇、来源

采用 **Torsten Hägerstrand《Innovation Diffusion as a Spatial Process》(1968)** 的
Model III 变体。这是人文地理学中空间扩散的标准模型，已有六十年的文献积累。

本项目在设计过程中独立推到了这个模型上，现按学术版本对齐并补足缺失部分。

| Hägerstrand | 本项目 |
|---|---|
| Mean Information Field —— 接触概率随距离衰减 | 沿航线网络的距离衰减 |
| Absorbing barrier —— 完全吸收，扩散终止 | 吸收型障碍（赤道永暴带） |
| Reflecting barrier —— 反射回本地，本地强度升高 | 反射型障碍（孤悬散岛的死胡同） |
| Resistance —— **接触 ≠ 采纳** | **采纳阻力**（本项目原缺，见第三节） |
| Monte Carlo 模拟 | 实现时可选；确定性场版本亦可 |

> 📌 **调查结论**：现有开源工具（Azgaar's Fantasy Map Generator、cultureforge、
> World-Generator、worldengine 等）**全部把文化当作分配给区域的离散标签**，
> 从中心 flood-fill 扩张，产生硬边界——正是本项目已作废的模型。
> 无工具可用，需自建。

---

## 一、核心公式

对于特征 `t`（起源于 `o`）在地点 `j` 的强度：

```
strength(t, j) = reach(t, o→j) × adopt(t, j)
```

### 1.1 reach —— 能不能传到

```
reach(t, o→j) = Π  permeability[b][mode(t)]   ×   exp( -λ_t · cost(o, j) )
                b ∈ path(o,j)
```

| 项 | 含义 |
|---|---|
| `mode(t)` | 该特征的**传播模式**：日常往来 / 商旅 / 使节学问 / 人口迁徙 |
| `permeability[b][mode]` | 障碍 `b` 对该模式的通过率 ∈ [0,1] |
| `path(o,j)` | 航线网络上的**加权最短路**（顺风权重小、逆风权重大） |
| `cost(o,j)` | 该路径的总代价 |
| `λ_t` | 该特征的距离衰减率 |

**关键**：`path` 走的是**航线网络**，不是空间直线距离（`02` 第四节推论一）。

### 1.2 adopt —— 传到了接不接受

```
adopt(t, j) = 1 − resistance(t) · conflict(t, j)
```

| 项 | 含义 |
|---|---|
| `resistance(t)` | 该特征的**采纳阻力** ∈ [0,1]，见第三节 |
| `conflict(t, j)` | 地点 `j` 已有的、与 `t` 竞争同一槽位的特征的最大强度 |

- 本地无冲突特征 → `adopt = 1`，畅通无阻
- 本地有强冲突特征 + 高阻力 → `adopt → 0`，传到了也不要

## 二、槽位与竞争

特征不是孤立的，而是成组竞争同一个**槽位**：

```
TraitSlot {
  id        // 「白麻的用途」
  values[]  // 丧服 / 喜服 / 无特殊含义
}

CulturalTrait {
  id
  slot          // 属于哪个槽位
  mode          // 传播模式（四选一）
  resistance    // 采纳阻力 0~1
  origin        // 起源地
  lambda        // 距离衰减率
}
```

在任一地点，同槽位各值的 `strength` **归一化**后，即为当地的**比例分布**：

> 「此地白麻作丧服的用法只剩约三成，多用于老辈人家；年轻人已不忌讳」

这正是 `08-地区设计规程.md` 要求的「写强度，不写有无」。

### 涌现性质：不需要地理障碍也能产生边界

两个高阻力特征互相竞争时，会在势均力敌处形成**陡峭的过渡**——
即使那里没有任何地理障碍。

**这是真实现象**：部分方言边界正是这样自发形成的。
它也意味着同言线有两种来源：**地理障碍** 与 **特征间的互斥**。

## 三、采纳阻力（本项目原缺的一层）

**接触 ≠ 采纳。** 信息到了，不等于人们会接受。

| 阻力 | 特征类型 | 为什么 |
|---|---|---|
| **低**（0.0–0.2） | 器物、作物、货币、度量单位、农具、食材 | 与既有的东西不冲突，好用就用 |
| **中**（0.3–0.6） | 文字、历法、律法形制、建筑样式 | 个人无所谓，但**需要国家推行**才铺得开 |
| **高**（0.7–1.0） | 丧俗、婚俗、亲属制度、世系、称谓分寸、世界观 | **与本地既有的深度冲突**，接受它等于否认自己 |

### 它解释了一个此前只有结论没有理由的现象

`04` 第三节说「日常往来类特征传得最近」。此前的理由只有一条：
它们靠最弱的传播模式。

**现在有了第二条：它们的采纳阻力也最高。双重原因。**

### 它给出一个新的可玩点

> **有些东西是传到了但被明确拒绝的。**

玩家在某地看到一样家乡的器物用得好好的，但家乡的规矩在这里被明令不用——
**不是没传到，是不要。** 这比"没传到"有攻击性得多，也真实得多。

## 四、障碍的三种类型

| 类型 | 行为 | 本世界的实例 |
|---|---|---|
| **吸收型** Absorbing | 扩散在此终止，通过率≈0 | **赤道永暴带**（障碍 A） |
| **反射型** Reflecting | 扩散被弹回，**本地强度反而升高** | **孤悬散岛**：文化在死胡同里积累不外流，形成高度独特的孤岛文化 |
| **改道型** Deflecting | 不阻断总量，**只改变路径** | **定点永暴 G**：直线被堵，往来被挤进南北绕道 → 中转岛垄断贸易 |

> 改道型是本项目在 Hägerstrand 二分法之外补的第三类。
> 它是「丝绸之路是被一场风暴逼出来的」这条推论的形式化。

## 五、生成管线（生成器的执行顺序）

严格遵循 `08-地区设计规程.md` 的硬流程：**先地理，后文化。**

```
① 行星参数     自转速率、轴倾角、恒星辐射
      ↓
② 大气环流     三圈环流 → 纬度风带（全球皆海洋 → 接近纯行星风系，极规则）；这是未受岛群扰动的背景态
      ↓
③ 岛群分布     浮石板块（汇聚脊 / 离散谷 / 走滑错断 / 热点链）决定密度与岛龄 → 陆地 = 势力范围 × 陆地占比
              → 主岛与岛体墙高 → 分类为 密接/中疏/稀疏/孤悬/叠层（叠层 = 板块汇聚带）
      ↓
④ 气候         ②b 岛对风的扰动：岛群是一排悬空的山 → 障碍场 → 摩擦 / 绕流 / 尾流 → 带界推成波状线（局部带界）
              → 上风水汽追踪降水（雨影、赤道湿 / 副热带干 / 中纬湿都算出来）+ 温度 + 风暴 + 河流；识别永暴带与无风带
      ↓
⑤ 障碍识别     由 ③④ 推出障碍及其「四模式 × 通过率」矩阵（带障碍按局部带界归一化）；标注三种类型
      ↓
⑥ 航线网络     成本加权图；顺风廉价、逆风昂贵、绕开改道型障碍
      ↓
⑦ 文明中心     在「降水 + 稳定气候 + 高岛密度 + 岛群陆地 + 谷物季节门槛（冬温）」同时满足处生成，窗在温带 30–42°（骨架第二版；陆地不是海拔，不违原则乙）
      ↓
⑧ 特征场扩散   对每条特征跑第一节的公式；同槽位归一化
      ↓
⑨ 政治层       人口（可耕地 × 降水）→ 诸邦（控制力 = exp(−后勤成本/半径)，能架桥短渡的才便宜 → 帝国只能长在密接群岛）
              → 采邑树（分封 = 运输成本的产物）→ 宗主 / 附庸 → 变法之国（中心 ② 圈、密接边缘）→ 兼并史与占领消化阶段
              政体是离散的，文化仍是 ⑧ 的连续场；两者不互相回写
      ↓
⑩ 输出         地图 + 各地特征强度表 + 九格表草稿（①③④ 邑级、⑤⑥⑧ 邦级、⑨ 连续场）
```

**每一步的输出是下一步的输入，不可跳步、不可倒序。**

**图上的节点是岛群，不是单岛**（`11` 第十一节）：一个节点 = 一个岛群 = 一个邑 = 一个水共同体；
群内小岛属第三层，按需生成，不进管线。③ 的分类阈值量的是群与群之间的间距。

## 六、约束（来自 `01-设计铁律.md`）

生成器必须遵守：

1. **除浮石外无超自然要素**；浮石只解释「为什么是岛、为什么飞」，不参与任何社会计算
2. **地理决定生产方式，不决定人的贵贱**——不得生成基于海拔/方位的阶级
3. **地质是背景**，板块尺度，不得有任何机制依赖它
4. **世界的每个角落都有人**——不得生成无人区
5. **文化是连续场**——任何输出如果让相邻两地读起来像两个国家，即为错误
6. **政治单位是离散的，但不回写文化**——邦界不是文化边界；⑨ 只读 ①–⑧，不改任何上游场

## 七、实现注意

- **确定性优先**：同一 seed 必须产出同一世界。便于迭代与复现。
- **中间产物全部可导出**：风带、岛屿、障碍、航线图、每条特征的强度场，
  都要能单独看。**调试这套东西全靠看中间层。**
- **参数外置**：所有通过率、阻力、衰减率写在配置文件里，可反复调。
- **Monte Carlo 可选**：确定性场版本已足够；若要"历史感"（谁先谁后），
  再上 Hägerstrand 的 Monte Carlo 版本。

## 八、验收标准

生成结果必须能产出以下现象，否则模型实现有误：

| # | 现象 | 检验方式 |
|---|---|---|
| 1 | **相邻两地几乎相同** | 任取相邻两点，特征分布差异应极小 |
| 2 | **走远了才明显不同** | 沿航线取样，差异应单调累积 |
| 3 | **同言线互不重合** | 不同特征的陡变位置不应对齐 |
| 4 | **文书通、口音不通** | 隔宽空域但有官方航路的两地：`使节学问`类特征高度一致，`日常往来`类完全不同 |
| 5 | **单向传播** | 逆风带两侧：上风地的特征在下风地有，反之没有 |
| 6 | **改道产生贸易枢纽** | 改道型障碍周围的绕道节点，应是各文明圈特征的混合体 |
| 7 | **传到了但不要** | 应存在 `reach` 高而 `adopt` 低的地点 |
| 8 | **帝国只能长在密接群岛**（第 ⑨ 步） | 密接之都的邦明显大于中疏之都的邦；宗主不是圈内最大邦；变法之国在中心 ② 圈的密接边缘且已开始兼并；船团不建国 |
