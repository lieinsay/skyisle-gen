# 上游规格快照

本目录的 `11`、`12` 是从 Zhouzhu 设计仓（`github.com/lieinsay/Zhouzhu`）复制进来的两份规格（本仓库当时还叫 `zhouzhu-gen`），
在 `7c499bc` 那一版的状态，随本仓库一起走，生成器的实现以它们为准：

| 文件 | 作用 |
|---|---|
| `11-世界总图.md` | 行星骨架定稿：风系、永暴带、大区块、三个文明中心、带界（8/28/36/62°）、历法（一年 336 日、轴倾角 34°） |
| `12-扩散模型.md` | 形式规格：Hägerstrand Model III 变体、reach × adopt、槽位竞争、十步生成管线、验收标准 |
| `13-浮石与陆地的生灭.md` | **本仓库自己写的正式设定**（2026-09-29，不是快照；09-30 第二版）：浮石的性质（热充、浮力随高度减弱得快、热要在骨架里放出来才充得进、浮力看结构、浮力朝天、扣住跟结构挂钩、闭孔）、没有火山与嵌合成山、岛的两层构造与地下水、特殊的山、一块陆地的一生与永暴回收、人怎么控制浮石、造船的门槛、荒地有主领照开垦；第二个超自然要素集水核；高度、大气与气候（大气比地球厚一倍多、云盖逆温、弱的岛群季风）；与旧设定 `01`、`02 §九`、`11`、`12` 等的逐句关系；未定的建议在第七节 |

**这是快照，不是同步副本。** Zhouzhu 那边此后怎么改，与本仓库无关；
本仓库要改口径，就直接改这两份，并在 `docs/DESIGN-NOTES.md` 里记一笔。`13` 第六节逐句列了它们与 `13` 不合的地方（`12` 第六节约束 1 已加注）。
