# 上游规格快照

本目录是从 Zhouzhu 设计仓（`github.com/lieinsay/Zhouzhu`）复制进来的两份规格（本仓库当时还叫 `zhouzhu-gen`），
在 `7c499bc` 那一版的状态，随本仓库一起走，生成器的实现以它们为准：

| 文件 | 作用 |
|---|---|
| `11-世界总图.md` | 行星骨架定稿：风系、永暴带、大区块、三个文明中心、带界（8/28/36/62°）、历法（一年 336 日、轴倾角 34°） |
| `12-扩散模型.md` | 形式规格：Hägerstrand Model III 变体、reach × adopt、槽位竞争、十步生成管线、验收标准 |

**这是快照，不是同步副本。** Zhouzhu 那边此后怎么改，与本仓库无关；
本仓库要改口径，就直接改这两份，并在 `docs/DESIGN-NOTES.md` 里记一笔。

其余上游文档（`01-设计铁律`、`02-世界与地理`、`04-社会与变迁`、`07-核心循环`、`08-地区设计规程`）
没有带过来。`docs/` 下的历史记录里凡是写 `docs/0X-…` 的，指的都是那边的文档。
